# Devops-Learning-AWS

## Introduction
- This repository contains the AWS assignments I’ve completed as part of my cloud learning journey.
- Each folder focuses on a practical task that reinforces real-world cloud concepts like networking, routing, load balancing, and secure infrastructure design.
- Rather than just reading theory, these projects allowed me to build the core pieces of AWS architecture from scratch — the same foundations used in production environments.

## Content

## VPC & Networking Assignment
- This assignment walks through creating an entire VPC environment manually, step by step. It covers the fundamentals of cloud networking.

## Application Load Balancer Assignment
- This assignment focuses on deploying multiple EC2 instances behind an Application Load Balancer.
